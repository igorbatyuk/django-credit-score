# Інструкція як запустити проєкт

## Швидкий старт (всі команди разом)

```bash
# 1. Встановити бібліотеки
pip install -r requirements.txt

# 2. Навчити модель (відкрити notebook і запустити всі комірки)
python -m notebook "data_science/loan_prediction_analysis.ipynb"

# 3. Налаштувати Django
cd web_app
python manage.py makemigrations
python manage.py migrate

# 4. Запустити сервер
python manage.py runserver
```

Потім відкрити браузер: **http://127.0.0.1:8000/**
